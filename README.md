在本机原浏览器打开 **http://127.0.0.1:3107**。如服务未启动，在`03-前端原型`使用Node.js 24运行`npm ci`、`npm run build -- --webpack`、`npm run start -- --port 3107`；开发模式可用`npm run dev -- --port 3107`。服务仅监听回环地址。

项目元数据保存在LocalStorage，材料正文、蓝图和审查保存在IndexedDB；本机受限`runtime-data`保存配置、目录登记、测评账本及SQLite创作任务/摘要缓存。任务结果与通过快照保留7天，服务中断不会自动重跑付费调用。清除浏览器数据会丢失浏览器档案，GitHub同步不是创作数据备份。

长原剧本拆解支持12 MB输入、2000份材料，超过单次容量自动分段；**后续蓝图、全文生成和审查仍有单次容量限制**。正式创作尚无累计费用账本，测评10元估算上限只覆盖测评。完整边界见验收清单及前端README。

GitHub仅保存代码、需求、测试及已授权演示快照。真实材料、运行数据库和密钥不提交。同步入口为`python3 scripts/sync-github.py --message "更新说明"`，没有后台自动上传。素材授权见[NOTICE](NOTICE.md)，代码许可见[LICENSE](LICENSE)，本机安全边界见[SECURITY](SECURITY.md)。
