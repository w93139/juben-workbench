# AI剧本杀原创改写工作台

简体中文创作工具，按五步组织：**准备材料 → 确定创作方案 → 设计故事 → 生成与检查 → 试玩与导出**。参考拆解、机制提炼与原创方向合并到第二步，原有能力保留。

当前是本地Mock前端原型。A基础、B参考研究已完成开发，本轮交付C故事蓝图编辑；按A—E五批等权计算，原型开发进度为 **3/5（60%）**，不含真实后端。A已由用户验收，B未记录正式验收结论，C待用户体验；D生成与审查、E试玩与导出主体仍待开发。

“设计故事”支持建立空白或演示蓝图，编辑人物、关系、时间线、信息、线索、轮次、主持与终局，保存草稿和命名历史版本。关系图跟随关联更新，基础检查提示缺项、断链和因果循环；这些提示不等于AI审查或真人试玩。真实后端、OCR与模型调用尚未实现。

顶部保留当前页面、一个主操作、修改决定和一个检查入口，下方具体内容单独滚动。方向允许先存草稿，推荐不自动确认；项目输出目录统一设置，平时只显示位置和更改入口。旧九阶段地址、项目数据和默认输出子目录继续兼容。

## 仓库保存范围

私有仓库保存产品需求、应用代码、类型与服务接口、演示快照、测试与开发计划。演示快照含《名字之外》的故事摘要和机制研究摘录，不是空数据结构。

原始参考材料、完整历史审查目录、agent-blueprint参考工程、个人Skill、依赖、构建产物、测试截图、密钥与真实数据库不上传。`scripts/import-demo.py`是可选的本地重建工具，需要仓库外的只读原资料；普通启动、构建和测试不运行它。

网页中创建的项目当前保存于浏览器LocalStorage，目录授权引用保存于IndexedDB。GitHub同步不会备份这些状态，也不是数据库服务。真实项目持久化、文件存储与恢复列入后端计划。

每轮开发完成适用验证后，通过`python3 scripts/sync-github.py --message "说明这次更新"`提交并同步。也可在Mac双击`同步到GitHub.command`。没有安装后台监听程序，每次保存文件不会自动上传。
