# AI 剧本杀策划工作台

本机辅助创作工具：**准备材料 → 拆解与作者大纲 → 创作蓝图 → 策划交接包**。

保留材料读取/OCR、前段模型调用、人工编辑、来源定位、项目预算与备份。交付 Markdown/JSON 策划方案，后续写作及核验建议可自行选用。应用不再执行正文改写或自动交叉审查；真人试玩、外部作者执行与完整剧本质量不属于本产品验收。

## 使用

在 `03-前端原型` 使用 Node.js 24：`npm ci`，然后 `npm run dev -- --port 3107`。本机地址 http://127.0.0.1:3107 。生产预览及配置见[应用说明](03-前端原型/README.md)。

拆解和生成蓝图需要服务端模型连接及项目预算，每次先查看费用预览再确认。编辑和策划包导出不调用模型。旧正文、报告与阶段成果保留只读，不恢复后段执行入口。
