# AI剧本杀原创改写工作台

当前流程：**准备材料 → 拆解与方向 → 创作蓝图 → 交叉验证与导出**。上传完整剧本，实际读取正文，选择原创方向，通过主模型协调两模型交叉审查后导出。界面主色#333333；四步与输出位置固定在顶部，主要操作在右下角。

本轮已从Mock界面切换为本机文件读取和真实模型接口。文本/PDF/图片可以实际提取文字，macOS支持本机OCR和系统目录选择。**尚未配置真实模型，尚未完成模型端到端联调**；未连接时禁止AI操作，不显示演示分析结果。

在03-前端原型使用Node.js 24执行`npm ci`、`npm run dev -- --port 3107`，浏览器打开 http://127.0.0.1:3107 。本机接口只接受回环同源请求。密钥仅使用本机服务端环境配置，禁止提交GitHub或保存在浏览器中。

项目元数据/旧记录保存在LocalStorage，新正文、蓝图、审查保存在IndexedDB；输出目录注册在忽略的runtime-data。清除网站数据会失去浏览器档案。旧版用户资料保留，可在列表下载旧版记录；旧版只登记名称的文件须重新选择才可读取。

GitHub只保存产品代码、需求及已授权演示快照，不保存真实上传材料、个人项目、模型密钥或运行数据。完成验证后运行`python3 scripts/sync-github.py --message "更新说明"`同步；没有后台每次保存自动上传。素材授权见[NOTICE](NOTICE.md)，开源见[LICENSE](LICENSE)，密钥保护见[SECURITY](SECURITY.md)。
