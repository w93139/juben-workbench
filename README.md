## 仓库保存范围

私有仓库保存产品需求、应用代码、类型与服务接口、演示快照、测试与开发计划。演示快照含《名字之外》的故事摘要和机制研究摘录，不是空数据结构。

原始参考材料、完整历史审查目录、agent-blueprint参考工程、个人Skill、依赖、构建产物、测试截图、密钥与真实数据库不上传。`scripts/import-demo.py`是可选的本地重建工具，需要仓库外的只读原资料；普通启动、构建和测试不运行它。

网页中创建的项目当前保存于浏览器LocalStorage，目录授权引用保存于IndexedDB。GitHub同步不会备份这些状态，也不是数据库服务。真实项目持久化、文件存储与恢复列入后端计划。

每轮开发完成适用验证后，通过`python3 scripts/sync-github.py --message "说明这次更新"`提交并同步。也可在Mac双击`同步到GitHub.command`。没有安装后台监听程序，每次保存文件不会自动上传。
