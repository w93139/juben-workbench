# 第一阶段：拆解诊断与受控验证

第一阶段实施基线：fb5b66f。代码在独立 worktree；当时未更新现用 3107 服务、未推送远程。后续 GitHub 同步见本文末尾。

目标：逐次记录分段、合并和最终汇总的安全诊断，硬性限制模型调用次数，提供不外呼、不清缓存的计划检查及默认关闭的单批真实验证入口。

不做：真实付费请求、整本重传/OCR、删除运行数据、调整分段或模型额度、正文/交叉审查重构、旧组件清理。

完成条件：旧任务可读；原缓存身份保持；未知用量保持未知；敏感嵌套字段不进入诊断；次数限制在发送前生效；诊断失败不遮蔽原始错误；dry-run 零模型调用且不清理缓存；真实验证一次发送后停止并有持久防重复记录，计费依据不足时零外呼。

验证：聚焦单元、完整单元、typecheck、lint、隔离生产构建、相关 E2E、仓库扫描及独立只读审查。所有运行数据在隔离副本或临时目录，模型使用假 transport。

风险：原用户浏览器尚未定位，当前可访问 Ego origin 无项目。服务器备份不含原始输入。蚂蚁公开价格结构已改变，max_tokens 计费含义及平台内部重试费用未知，不能将估算当作金额硬上限。真实调用须另有明确输入、计费依据与用户授权。
