# 本间工作台 · 策划辅助

四步：**准备材料 → 拆解与作者大纲 → 创作蓝图 → 策划交接包**。正文改写、自动交叉审查和真人试玩不属于当前产品交付。旧成果只读，相关数据结构保留兼容。

## 启动与检查

Node.js 24、npm 11。在本目录运行：

```sh
npm ci
npm run dev -- --port 3107
```

生产预览：`npm run build -- --webpack` 后 `npm run start -- --port 3107`。服务仅监听 `127.0.0.1`。本机 OCR 需要 macOS 的 osascript、Swift、PDFKit、Vision 与 textutil。

根目录执行 `python3 scripts/verify-app.py`，隔离源码与构建，清除模型环境变量并使用假供应商运行 lint、单测、构建、类型检查、浏览器回归。不会更新用户正在使用的服务。

## 使用流程

1. 导入材料，核对未读取项并明确排除。原文件不修改。
2. 查看拆解费用并确认；选择方向、修订大纲并保存。作者内容绑定实际分析轮次；重新分析后的旧稿需显式采用。未保存或暂存失败会提示，不能绕过进行付费。
3. 编辑蓝图九类结构。独立草稿最多 12 份，历史最多 20 份；预览后提交正式版。容量满时由作者明确整理，不静默丢弃。冲突时保留输入。
4. 下载策划 Markdown/JSON。包含来源定位、大纲、蓝图、逐件写作任务与可选核验建议；不执行这些后续任务。来源位置可对应不等于内容已逐条核实。

公共线索需无指定角色且发放方式完整匹配约定标记（如“公开”“主持公开发放”）；自由文本不清楚时保留在主持待确认，不自动放入公共卡。整包含主持秘密，不可直接发给玩家。

## 模型与费用

页面“配置模型”保存服务端连接；拆解可用单独拆解模型或回退主模型，蓝图需要主模型。旧审查模型配置保留兼容，但无需为策划交付补齐。固定小样测评为可选独立工具，模型得分不代表作者已接受内容。

服务端也支持 `STUDIO_API_BASE_URL`、`STUDIO_API_KEY`、`STUDIO_MAIN_MODEL` 等环境配置；环境整组优先，页面只读。密钥只保存在被忽略的受限服务端配置，不进入浏览器持久存储或 Git。配置存在不表示已实测。

每个项目单独设置累计额度；拆解/蓝图先预览调用规模、估算与剩余额度，确认后才外呼。预览绑定当前材料、模型和预算版本，有效期 10 分钟。忙时最高价预留、闲时最低价展示；每次调用记录用量，异常费用保留待核对。平台最终账单为准，失败调用也可能收费。固定小样测评有独立账本，不占用或代替项目预算。

编辑、历史查询、备份与策划包构建不调用模型。已退役正文/审查在路由和引擎均拒绝启动；不提供自动继续旧付费链。

## 保存与恢复

项目索引在 LocalStorage，材料、分析、蓝图和历史在 IndexedDB；作者未保存编辑使用 SessionStorage 独立标签页暂存与内存保护，暂存成功可刷新恢复，关闭标签页前须保存作者修订。蓝图草稿独立保存。强制退出/清除站点数据仍可能丢失尚未落盘输入。

服务端 `runtime-data` 保存受限配置、目录登记、任务 SQLite、摘要缓存与费用账本。中断不自动重跑付费任务；查询失败不表示零费用。结果缓存有保留期限，不能替代项目备份。历史正文/审查结果和旧 ZIP 资格校验保留，只读导出仍需原服务端有效凭证，导入备份不会制造通过资格。

项目标题旁可“备份项目”，列表页可“从备份恢复”为新副本。读取 v1–v4 备份；保留已有材料、作者修订、蓝图与历史成果，运行态转中断。不备份目录权限、磁盘原件、模型配置、账本与服务端通过凭证。恢复后预算与目录另行设置。GitHub 同步不等于创作数据备份。

## 处理限制

- 每批 2000 份材料，单文件 25 MB、单正文 300000 字符、PDF 60 页、图像 4000 万像素。
- 拆解 JSON 输入最多 12000000 字节；大材料分段及逐层合并，最多 512 批，引用保留。统计覆盖不保证语义无遗漏。
- 单模型数据载荷 600000 字节，单回复 2 MB；蓝图仍须适配单次容量。
- 完整项目备份最多 64 MiB，超限拒绝且不截断。
- 无账号系统、云端备份、音视频转写与压缩包导入。
