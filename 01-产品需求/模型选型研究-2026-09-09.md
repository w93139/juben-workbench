# 模型选型：先研究，再定向验证

核对日期：2026-09-09。适用于本间工作台的剧本拆解、原创方向设计与交叉审查。公开资料用于筛选候选，不能代替当前账号接口验证、完整作品检查或真人试玩。

## 固定候选

首批最多3个模型，每个回答结构与证据、原创方向、一致性审查三道合成题。只设1个替补；未达到条件时明确停止，不自动遍历平台模型。

| 模型及平台ID | 待验证的用途 | 入围依据与限制 |
| --- | --- | --- |
| Qwen3.8-Max / `qwen3.8-max` | 拆解与原创方向 | 官方支持长文档、结构化输出；公开创意写作评测有对应名称。平台别名与官方日期快照未必相同，不能照搬榜单成绩。 |
| DeepSeek-V4-Pro-0813 / `deepseek-v4-pro-0813` | 因果与证据审查、核对其他模型意见 | 官方明确0813版本、长上下文和JSON能力。推理能力是入围依据，不证明剧本杀专项效果。 |
| Kimi K3 / `kimi-k3` | 跨角色信息与独立复核 | 官方长程知识工作定位，补充另一家模型视角。用户已有K3历史验证经验，但不等于本次平台部署已通过。价格较高，只做必要验证。 |
| DeepSeek-V4-Flash-0731 / `deepseek-v4-flash-0731` | 唯一低成本替补 | 在主候选不可用或返回不完整时替补；与Pro同家族，审查视角可能更接近。 |

主模型和两路审查的最终分配仍由本地三题结果和质量门槛决定；表中用途是验证重点，不是已经通过的角色配置。GLM等未纳入这一批是为了收敛范围，不代表模型能力差。

## 证据及可信边界

- [Qwen官方规格](https://help.aliyun.com/en/model-studio/qwen3-8-max)：文档能力与结构化输出的依据。平台未给日期快照时，不冒称与官方某快照完全相同。
- [DeepSeek官方API规格](https://api-docs.deepseek.com/quick_start/pricing/)、[Pro-0813模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro-0813)：核对版本、接口与能力范围。
- [Kimi K3官方模型卡](https://huggingface.co/moonshotai/Kimi-K3)：核对长上下文及模型定位。
- [Arena创意写作原始榜单](https://arena.ai/leaderboard/text/creative-writing)：作为写作候选信号；模型版本、推理档位和偏好评测方式与本应用不同。不能把编码或综合排名当作剧本质量排名。
- [Artificial Analysis原始模型对比](https://artificialanalysis.ai/models/comparisons/kimi-k3-low-vs-deepseek-v4-flash)：补充长上下文与推理档位差异参考，不直接采用排名作自动选型。
- [蚂蚁公开目录](https://maas.antdigital.com/api/v1/model-service/public/page-list?page=1&pageSize=500)：当前平台规格与人民币报价。公开目录存在不等于用户Key一定可用，运行时还会免费核对账号清单。

公开目录当日输入/输出价（元/百万Token）：Qwen 10.8/32.4，Pro 3.375/10.125，Kimi 17/85，Flash 1.05/3.15。它们是查询快照，不是账单承诺；执行计划重新获取报价并保留原费用上限。

平台把Kimi标为多模态理解模型，它也支持文本对话，不能仅因分类不是“文本生成”就误排除。该目录同时声明Qwen、Pro、Kimi不支持temperature参数；工作台不再为这三款强制发送该可选参数，Flash维持原参数。这里只使用文本输入，未接入图像或视频测评。

## 工作台执行规则

1. 推荐清单作为独立、带日期和来源的数据维护；打开配置页可查看理由。当前没有自动联网搜榜或新模型弹窗。
2. 免费核对账号权限、上下文、接口格式支持和人民币价格，先选3个首选，缺位时用唯一替补。清单不足3个即停止，不选其他模型。
3. 已有同评分规则的研究候选成绩复用，只验证缺题；清单外成绩保存在原子归档的旧报告。历史累计费用不清零。
4. 旧任务结束后可点击“准备针对性测评（免费）”，看新计划再主动开始。准备与刷新不会调用模型。前轮未完整返回的失败候选不会因这次重规划重新调用。
5. 服务重启或费用不明不能借新计划绕过阻断。界面把等待、完整回答但低分、截断、服务异常分别表达。进度按完成题目更新，第一题等待时保持可见底轨和运行提示。
6. 小样分数由工作台规则计算，LiteLLM不负责给这些剧本分数；网上评测不代替本地验证，也不自动触发收费。
