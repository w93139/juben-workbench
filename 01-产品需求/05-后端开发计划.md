## 数据存放原则

| 内容 | 位置 |
|---|---|
| 代码、结构/迁移、非敏感模板、测试、需求 | 指定GitHub仓库 |
| 当前项目元数据/正文/蓝图/审查 | 浏览器LocalStorage/IndexedDB |
| 当前模型配置、目录登记、测评账本、任务/摘要缓存 | 本机被Git忽略的runtime-data；环境变量配置也只在服务端 |
| 后续长期项目/版本 | 受权限保护的数据库；具体选型在存储批次落实 |
| 原始材料及成品文件 | 本机原目录/输出目录；将来按授权接文件或对象存储 |
| 密钥 | 本机受限服务端配置或部署Secret，禁止Git/客户端持久存储 |

GitHub代码同步和创作数据备份分开验收；清理浏览器、缓存或本机目录前需有可验证的恢复方案。接入安全边界见[SECURITY](../SECURITY.md)。
