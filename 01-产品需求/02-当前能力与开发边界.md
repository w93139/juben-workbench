# 当前能力与开发边界

当前产品止于策划交接包，详细验收以 [06](06-当前验收清单.md) 为准。

| 能力 | 边界 |
|---|---|
| 项目与材料 | 新建、读取文本/文档、本机 OCR、排除不可读项；不修改原件 |
| 拆解 | 模型大纲、候选方向、来源定位；长材料分段处理；调用前预览费用 |
| 作者整理 | 修改大纲/方向/要求；作者版本绑定具体分析结果；过期内容保留供显式采用 |
| 蓝图 | 九类节点编辑、关联检查、独立草稿、历史版本；结构检查不判断故事质量 |
| 策划交接 | 本地生成 Markdown/JSON：大纲、蓝图、分角色/轮次任务与可选核验建议；含主持秘密 |
| 数据与预算 | 浏览器项目备份/恢复、本机 SQLite 任务及费用账本；已有正文/审查只读 |

## 已取消

应用内正文生成、自动交叉审查和以完整剧本为交付目标的 M6 计划。真人试玩与外部作者执行为“不适用（产品范围外）”，不能列成待完成闸门。

## 实际限制

- 本机单用户，无账号、云备份或团队服务；浏览器数据与代码同步分别管理。
- 文件、模型载荷与备份有大小限制，见[应用说明](../03-前端原型/README.md)。
- 来源定位只证明引用指向已有材料，不等于逐条语义核实。
- 公共线索只接受明确完整公共标记且无指定角色；其他描述保留在主持待确认项。
- 作者判断大纲与蓝图是否符合意图；测试与假供应商回归只证明软件行为。
