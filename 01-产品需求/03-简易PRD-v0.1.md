# 策划辅助工作台 PRD

## 目标

帮助作者把已有材料整理为可编辑大纲、原创方向与结构蓝图，并导出可以继续写作的策划方案。产品完成标准是这些功能可靠且信息清楚，不包含完成整本改写剧本。

## 四步工作流

1. **准备材料**：读取本机文件，查看成功/失败与排除状态。必要材料未处理前不能开始拆解。
2. **拆解与作者大纲**：模型给出大纲、2–5 个方向和来源；作者可修改、选择方向及补充要求。修订绑定实际分析结果，重新拆解后旧稿保留但不自动采用。
3. **创作蓝图**：角色、关系、事件、信息、结论、线索、轮次、主持触发、终局可编辑。自动暂存草稿，显式提交正式版本；缺失关联清楚提示。
4. **策划交接包**：本地下载 Markdown/JSON，包含范围、材料定位、作者大纲、方向、正式蓝图、写作任务与可选核验建议。包内含主持信息，不能直接发给玩家。

## 必须满足

- 每次模型操作先显示调用规模、估算和剩余额度，确认后执行；编辑与导出零模型调用。
- 来源/结构/版本缺口明确显示；不把结构通过当作内容质量通过。
- 作者输入在无关字段保存、跨页和冲突时不会静默丢失；存储失败显示真实失败并保留输入。
- 旧分析、过期蓝图与当前成果可区分；导出期间变更不能下载旧包并标记成功。
- 指定角色的线索不得进入公共任务；自由文本权限不清时进入主持待确认。
- 原文、服务端配置与账本不自动入交接包；完整项目备份单独提供。
- 新正文/审查操作在 HTTP 和执行引擎均拒绝；旧结果、备份与费用记录仍可读。

## 范围外

正文改写执行、模型交叉验证执行、真人试玩、外部作者完成任务、Word/PDF 成品排版、账号与云部署。交接包中的后续建议可选，不增加产品验收条件。

## 验收

按 [06-当前验收清单](06-当前验收清单.md) 验证软件与策划输出；必需工程检查见 [TASK](../03-前端原型/TASK.md)。实际作者满意度由用户判断，不以模拟回归替代。
